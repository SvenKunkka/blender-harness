# Blender Harness — demo prompts

Paste these into the Web UI chat (or the AI Harness panel) one at a time.
Each prompt is one undoable "AI step" in History.

## Demo 1 — keyboard case from scratch
```
Create a 75% keyboard base: 325 × 145 × 18 mm, corner radius 6 mm, wall
thickness 2 mm, bottom thickness 2 mm. Name it KeyboardCase75.
```

## Demo 2 — mouse concept volume
```
Create a mouse concept volume: length 120 mm, width 64 mm, height 39 mm. The
highest point should sit roughly 45 mm from the rear of the volume.
```
> The current volume generator is symmetric (highest point in the middle).
> Follow-up with: "Move the tallest point toward the rear by shifting the volume
> shape — then render front and side views to check."

## Demo 3 — modify the selected enclosure
```
Take the selected enclosure and: increase width by 2 mm, keep length unchanged,
add a 1.5 mm bevel on the visible edges.
```

## Demo 4 — three variants side by side
```
Create three variants of the selected object: A = original height,
B = height -2 mm, C = height +2 mm. Arrange them side by side along X with
10 mm spacing between them.
```

## More one-liners
```
Round the top corners of the selected part to R3; keep the bottom edges sharp.
Drill a 4 mm ventilation hole grid into the selected plate: 6 columns × 2 rows,
spacing 8 mm, centered.
Measure the wall thickness of the selected shell at its thinnest point.
Add a 2 mm lip on the inside of the selected case so a PCB can sit on it.
Make the selected knob 2 mm shorter and give it a chamfered top edge.
Compare the two selected objects: which one is heavier-looking in volume?
```
